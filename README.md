# M.A.R.S-Project-
Create a Chrome Extension for medical students to help them learn medical terms for their professional life. Additionally, this extension can be used for other majors like psychology.

# Extension Set-Up
1. To enable JavaScript, go to Chrome settings -> Press "Privacy and Security" -> Press "Sites can use JavaScript".
2. Go to chrome://extensions/. On the top right, press the toggle switch to enable developer mode. 
3. Press "Load unpacked"
4. Find and select folder "chrome-for-colin" (<font color="red">WARNING: NOT "M.A.R.S-PROJECT"</font>)
5. Enable "word-scanner" by clicking on the toggle switch
6. When updating the code of the extension, press the "update" button.


# How-to-Use
1. Once enabled, find a website of your liking.
2. Press the icon for the word-scanner if pinned. If not pinned, press the puzzle piece icon and click word-scanner.
3. Write the word you want to look for. If more than one, seperate them with commas.
4. Press the blue "Scan Page" button
