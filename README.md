# M.A.R.S-Project-
Create a Chrome Extension for medical students to help them learn medical terms for their professional life. Additionally, this extension can be used for other majors like phycology.

#How-to-Use
1. Search up a website in Chrome (make sure you have javascript allowed in settings)
2. Enable the extension in chrome://extensions/ (use developer mode and load the file)
3. In the website click the extension (you should see a trash ui popup)
4. Type a term and click the search button
